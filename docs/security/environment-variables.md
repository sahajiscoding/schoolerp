# Environment Variables Classification\n\n## Public (safe in clients)\n- EXPO_PUBLIC_SUPABASE_URL\n- EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY (legacy: EXPO_PUBLIC_SUPABASE_ANON_KEY)\n- VITE_SUPABASE_URL\n- VITE_SUPABASE_PUBLISHABLE_KEY (legacy: VITE_SUPABASE_ANON_KEY)\n\n## Secret (server-side only)\n- SUPABASE_SERVICE_ROLE_KEY\n- SUPABASE_SECRET_KEY\n- SUPABASE_JWT_SECRET\n- POSTGRES_*\n- EXPO_ACCESS_TOKEN\n\nNever prefix secrets with EXPO_PUBLIC_ or VITE_. CI blocks them.
